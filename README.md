# Piggee-Telegram-Mini-App
Моя копилка — Piggee 🐷 Трекер накоплений по мотивам таблички-копилки: создай сетку ячеек как на физической копилке, зачеркни ячейку, когда положил деньги, — и следи за прогрессом. Работает как обычный сайт и как Telegram Mini App, данные хранятся локально. Один HTML-файл, без серверов и зависимостей.
